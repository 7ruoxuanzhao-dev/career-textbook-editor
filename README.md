# 生涯教材助手

生涯教材助手是一项面向高校写稿教师的中文 Agent Skill，适用于《大学生职业生涯规划》《大学生就业指导》等教材。拿到大纲准备动笔时，它帮你把“这一章要讲什么”细化为读者定位、正文小标题、案例线索和实践任务；已经写出初稿时，它参照本书样章逐节审读，指出哪些知识没有讲透、哪些表述生硬、哪些材料需要核实，并给出具体改法。

**所有输出仅供写稿参考。** 编写思路、完整章稿和优化稿均需教师审阅。请核对概念与理论出处、政策与数据的适用范围、校友事迹与引语，结合自己的教学经验和专业判断取舍、补充后定稿。

## 从手头的材料开始

| 我想做什么 | 我提供什么 | 我先收到什么 | 我确认后收到什么 |
|---|---|---|---|
| 编写新章节 | 大纲或编写方案、参照样章、目标章节 | 可修改的编写思路，包含各部分写作逻辑及拟用小标题 | 按已确认思路展开的完整章稿 |
| 优化已有章节 | 初稿、参照样章、编写方案 | 对应原文位置的审读意见和编号建议 | 按选定范围修改的完整稿件、代表性修改对照和待核事项 |

第一次使用，可先按下方[开始使用](#开始使用)选择适合自己助手的入口，再发送 **“启动生涯教材助手”**。

## 教师怎样参与编写和修改

**手头只有大纲时，选择“教材编写”。** 提供本书大纲或编写方案、可参照的样章，并说明要写哪一章。你先收到编写思路文件：每一部分先用一段话说明为什么这样讲，再列出拟用的正文小标题。文件还会交代读者定位、篇幅重点、可能需要的补充材料，并提供实践活动和可选的中华优秀传统文化素材。你可以调换两节的顺序、删去不适合本校的活动，也可以直接上传自己改过的思路。确认后，助手才据此展开完整章稿。

**手头已有初稿时，选择“稿件优化”。** 提供初稿、样章和编写方案。助手先从语言表达中的“AI感”、正文逻辑、知识准确性、体例结构四方面审读，结合原句说明判断依据，再列出带编号的优化方向。你可以回复“采用第2、4项，案例保留我的原话，数据只标出待核处”。确认后，助手按选定范围另存完整优化稿，附代表性修改对照，方便你回看改动是否忠实于原意。

## 它怎样帮助教师把稿子写实

- **让章节重点在落笔前就看得见。** 例如，“了解就业信息”和“判断招聘条件”适合安排不同的练习。前者需要学生找到可靠的信息来源，后者需要学生读出公告中的硬性条件。把学习任务落实到标题和材料，教师在提纲阶段就能发现讲解和练习是否对应。
- **区分正文、案例和活动各自的写法。** 正文讲清概念、依据和适用条件；案例留下能让学生理解人物选择的细节。例如，“她调整策略后顺利签约”略去了最值得讲的部分。若教师掌握访谈材料，可以补上她当时看到了哪条岗位要求、为什么改变投递方向。审读“AI感”也落实到这类具体问题，不以检测分数评价作者。
- **为校本经验留出位置。** 同一项岗位比较练习，在一所学校可以采用当地企业的招聘简章，在另一所学校可以采用毕业生的实习记录。助手会提示哪处补材料最有价值，涉及真实人物、校情或理论出处时标出“请编者核实”，由教师决定选材和表述。

| 你的助手支持什么 | 选择哪个文件 | 怎样启动 |
|---|---|---|
| 安装 Agent Skills | [下载技能包](career-textbook-editor.zip?raw=true)，或安装仓库中的同名技能目录 | 按平台说明导入，选中技能后发送“启动生涯教材助手”。 |
| 读取项目文件 | 从仓库的 Code 菜单下载 ZIP，解压并打开含技能子目录的文件夹 | 发送“请读取 career-textbook-editor/SKILL.md，启动生涯教材助手”。 |
| 上传文件或粘贴长文本 | [获取通用指令](生涯教材助手-通用指令.txt?raw=true)，其中已包含参考资料 | 上传文件或粘贴全文，发送“请按这份指令启动生涯教材助手”。 |

## 第一次可以这样问

**教材编写**

> 我在编写大学生就业指导教材。请根据附件中的大纲和样章，为“读懂招聘公告”一节拟订编写思路。请列出正文小标题，待我确认后再写稿。

**稿件优化**

> 这是章节初稿、编写方案和参照样章。学生读完案例后还不清楚怎样比较两个岗位，请重点审读这部分。先给我带编号的优化建议，保留原稿供我对照。

技能默认采用严谨、自然的中文教材书面语。案例可以保留人物对话与选择过程，正文则要交代判断的依据。交付格式取决于所用助手的能力：支持 Word 时可生成文档，只支持文字时交付可复制的正文与表格。教师定稿前应核实资料，并结合教学经验补充自己的判断。
