# 生涯教材助手

生涯教材助手为编写《大学生职业生涯规划》《大学生就业指导》的高校教师提供**教材编写**和**稿件优化**两项支持。

拿到“求职信息筛选”这样的章节题目，教师往往还要决定从哪里讲起：学生读完一则招聘公告，应该能判断什么？要给出哪些材料，学生才能比较两个岗位？助手会参照本书大纲和样章，把这些问题落实到各节的写作思路、正文小标题和实践活动中。教师可以调整讲解顺序，换入本校学生的经历，确认后再展开章稿。

已有初稿时，助手会指出哪些地方值得改，以及为什么改。例如，案例写到“学生调整了求职策略，最终顺利签约”，读者却看不出他根据什么作了调整。助手会标出这处缺失，建议教师补充当时的选择依据。教师确认修改范围后，再生成完整优化稿；涉及概念出处、数据和真实人物引语的疑问，留给编者逐项核实。

## 选择你的任务

| 手头的材料 | 先收到什么 | 确认后收到什么 |
|---|---|---|
| 教材大纲或编写方案、参照样章，以及要编写的章名 | **章节编写思路**。逐节说明为什么这样写，列出拟用小标题，并建议篇幅、补充材料、实践活动及可选文化素材。 | 按确认的思路撰写的完整章稿。需要核实的概念、理论和校本事实会标在相应位置。 |
| 教师初稿、参照样章和编写方案 | **优化建议稿**。结合原句审读程式化表达、正文逻辑、知识准确性与体例，列出带编号的修改建议。 | 按教师选定范围形成的优化稿，附代表性修改对照和待核事项。 |

例如，教师可以回复“采用第2、4项，保留原案例，理论出处标给我核实”。助手会据此调整稿件。审读“AI感”时，关注的是学生读到哪里会困惑、哪一段需要改写，不对作者身份作推断。

## 第一次可以这样问

**教材编写**

> 我在编写大学生就业指导教材。请根据附件中的大纲和样章，为“读懂招聘公告”一节拟订编写思路。请列出正文小标题，待我确认后再写稿。

**稿件优化**

> 这是章节初稿、编写方案和参照样章。学生读完案例后还不清楚怎样比较两个岗位，请重点审读这部分。先给我带编号的优化建议，保留原稿供我对照。

技能默认采用严谨、自然的中文教材书面语。案例可以保留人物对话与选择过程，正文则要交代判断的依据。交付格式取决于所用助手的能力：支持 Word 时可生成文档，只支持文字时交付可复制的正文与表格。教师定稿前应核实资料，并结合教学经验补充自己的判断。
