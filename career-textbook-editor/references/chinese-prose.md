# 中文教材句段审校

先连读一个小节，辨明这段话是谁对谁说的、要说明什么。审校结论分成三类：语法或逻辑有误，指出误在何处并修正；语法成立但表达生硬，结合语境酌改；句式虽常见但承担了明确功能，保留。以下未注明出处的句子均为自拟示例。

## 常见的程式化表达及判断方法

起草和统稿都按文字的用途选择语体。知识正文用客观陈述讲清工作主体、判断依据和适用条件。案例叙述保留现场细节，人物原话能揭示误解、选择或沟通方法时保留。实践栏目可直接提出问题或要求，写清所需成果，省去陪伴式提醒。面向高职学生时，用熟悉的岗位和具体材料降低理解难度。

案例可以从影响选择的一处细节写起。例如，学生为展品写了很长的说明，同伴试读时却分不清眼前两件展品。是缩短文字，还是补充辨识特征？这个问题可留给学生依据展品材料判断。真实人物的动作和对白须有材料依据。回到正文后，应说明能够迁移到其他任务的方法。

“你从哪里知道这件展品的用途？”适合用作活动中的提问。正文可写为“展签中的用途说明应能与藏品资料相互核验。”比较两句话，应看本段需要学生参与观察，还是理解写作依据。

| 阅读时遇到的形式 | 怎样判断、怎样改 |
|---|---|
| 相邻段落反复用“在……背景下”“随着……不断发展”开头 | 暂时删去背景句，看后文的条件或解释是否丢失。若整节已经交代背景，就从本段的新问题起笔；若招聘时间变化确实影响准备安排，保留具体时间关系。 |
| “赋能、抓手、维度、实现……的提升”等抽象词层层相接 | 找出动作及其主体。“开展对岗位需求的分析与个人优势的匹配”可写成“求职者可对照岗位要求，从实习或项目经历中选择能够说明相应能力的事例”。专业术语有明确含义时沿用。 |
| “不仅……更……”“从……到……”“既要……又要……”密集出现 | 读出各项之间究竟是递进、先后还是并列。有实质关系就保留；两半意思相同时合并，存在取舍时直接说明何时选哪一种。 |
| 三项排比、正反对举、段末口号反复收束 | 如“视野向外拓展，认识向深推进，行动向实处走”。逐项检查学生能据此完成什么。若本节实际要求比较两份岗位说明，应明确要比较哪项职责；流程确有三步时可保留分点。 |
| “首先、其次、再次、最后”依次引出互不相干的句子，或每段末尾都有“综上所述” | 给每段概括一个问题，按学生弄懂这件事的顺序排列。如果是时间步骤，保留序号；如果是解释原因，直接写出因果联系。末句仅复述首句时可删。 |
| 用“全面、精准、高效、深度”等评价词代替解释，或连续使用“只要……就一定……” | 找出原文能支持的程度和条件。“投递前核对专业限制，可以减少误投”比“精准匹配全面提升求职成功率”更清楚。涉及数据或效果时核对依据。 |

## 容易漏看的篇章问题

以下是面向生涯教育教材的编辑判断。连读上下文，能说明具体的理解障碍时才列入建议稿。每条先摘原句，再指出学生可能在哪里误读，并说明保留、局部修改或重组段落的理由。

| 线索 | 审读办法与保留条件 |
|---|---|
| **同一概念频繁换名** | 上段用“职业兴趣”，下段改称“职业偏好”，练习又要求填写“职业价值观”。沿着讲解和练习追踪学生究竟要判断什么。指同一概念时统一术语；确需区分兴趣与价值观时，补出区别。保留为首次学习者解释术语的通俗说法。 |
| **连接词把时间先后写成因果** | “小李修改简历后获得面试通知，由此可见，是项目描述打动了招聘方。”材料只能证实两件事先后发生。若有招聘方反馈，写明反馈内容；依据不足时保留时间顺序，去掉原因推断。 |
| **段落不断预告或评价自己的讲解** | 连续出现“接下来我们将深入探讨”“值得特别强调的是”“通过以上分析可以看出”。删去这些话再读：若知识完整、阅读顺序清楚，可以直接进入主题。章首提示学习顺序、跨节回指前文方法等确有导航作用的文字可以保留。 |
| **把两种选择写得面面俱到，却不提供取舍依据** | “考研和就业各有优势，应结合自身情况理性选择。”检查正文是否交代哪条信息会改变判断。例如，目标岗位是否把研究生学历列为报名条件？给出能查证的条件；材料尚不足以得出结论时，可保留开放结论并说明还要查什么。 |
| **案例有人名和结局，却看不见关键选择** | “小林主动调整策略，最终顺利签约。”请指出小林当时知道什么、改了哪一步，以及学生能据此学到什么。真实案例缺少细节时向编者约取原始资料；导入案例若有意停在决策前，可保留悬念，让学生使用已有线索判断。 |
| **任务套在任何专业都成立，材料却不足以完成任务** | 练习要求“根据该企业的用人需求完善简历”，前文却只写企业名称。检查学生能否仅凭所给材料完成指定动作。可提供岗位要求节选，或把查找正式招聘公告列为练习第一步。开放调查本就要求学生搜集资料时，应写清资料来源和成果要求。 |

## 逐句核查中文语法和表达

| 核查项 | 判断与改写示例 |
|---|---|
| 主语和谓语 | 先去掉长修饰语读主干。“通过这次访谈，使小陈了解了岗位要求”可改“小陈通过这次访谈了解了岗位要求”。上下文主语明确时，汉语允许承前省略。 |
| 主语转换与指代 | “小周向导师介绍了自己的求职打算，他建议先去实习”中“他”可能指两人。若建议来自导师，写成“听完后，导师建议小周先去实习”。身份不明确时回查原稿。 |
| 动宾、主谓和修饰语搭配 | 分别搭配并列项试读。“提升面试技巧和求职视野”可改为“改进面试技巧，拓宽求职视野”。保留教材中已有明确定义的概念。 |
| 定语、状语及其范围 | “仅要求应届生提交的材料”可能指只要求应届生提交，也可能指应届生只需提交这一份。先核实“仅”限定的是人还是材料，再分别写成“这份材料只需应届生提交”或“应届生只需提交这份材料”。 |
| 关联词与分句逻辑 | 区分必要条件、充分条件、因果、转折和时间先后。“只要符合报名条件，就会被录用”把报考资格写成录用保证。按原意可改“符合报名条件即可报名，录用结果还要看后续选拔”。 |
| 句式杂糅、赘余和否定 | “原因是由于材料不齐造成的”改为“原因是材料不齐”。遇到“防止……不再……”先还原作者想避免的结果，再决定删哪一重否定。 |
| 长定语、被动句与信息顺序 | 连续几个“的”时先找中心词。“由学院组织的面向毕业生开展的简历修改活动”可写“学院为毕业生组织了简历修改活动”。需要突出受影响者的被动句可保留。一个长句中若既讲条件又切换主体，按意思分句。 |
| 标点、列举和问句 | “岗位职责包括：布展和接待”在动词和宾语之间插入冒号，可改为“岗位职责包括布展和接待”。原文确实先有总说、随后逐项解释时，可保留冒号。 |

## 回读和交付

连读相邻两段。若前段已按甲、乙分述，后段又依同一次序复述，并以一串抽象名词作结，检查第二段究竟增加了什么。讲解岗位差异时，可以沿一项工作中实际发生的问题展开，让前一句的结果成为后一句的起点。确需逐项比较岗位条件时，保留并列或使用表格。避免仅靠变换连接词掩盖段落重复。

**按高校教材的语体复核。** 正文应保留承担教学功能的概念，并解释其对象、依据及适用条件。例如，“即时复盘”与“周期复盘”应从记录材料、观察范围和判断用途上加以区分。举例后应说明材料支持什么判断、还需核实什么。连续设问、生活化对白、第二人称指令适用于特定情境或实训栏目；若它们代替了正文中的方法讲解，应恢复论述。也要检查改稿是否只将口语换成抽象名词，却未增加解释。以学生能否独立运用方法为尺度。

1. 顺读改过的段落，检查上句提出的问题有没有下文，“这”“其”“由此”能否找到明确所指。教材正文用清楚、平实的书面语，案例对话保留人物口吻。作者引语、政策原文需要调整时，核对原文或改用间接转述。
2. 对照原稿检查人物、条件、时间、否定和结论强弱。不能确定原意时提出具体编辑疑问。尤其注意“可以”与“必须”、“部分岗位”与“所有岗位”的差别。
3. 稿件优化首轮将审校发现写入优化建议稿。教师确认修改范围后，再另存完整优化稿。核查表记录章节位置、可检索原句、问题类别、具体阅读障碍及改句。遇到反复出现的句型，给出代表例并复查本次指定的全文范围。词频仅供定位，不据此认定写作来源。
